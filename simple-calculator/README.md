# 🧮 Simple Calculator in C++

## 📌 Project Description

This is my first C++ programming project.

The Simple Calculator is a beginner-friendly program that performs basic mathematical operations using C++.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero protection
- Invalid operator detection

## 🛠️ Technologies Used

- C++
- G++ Compiler
- Visual Studio Code

## 📚 Concepts Used

- Variables and Data Types
- User Input and Output
- Arithmetic Operators
- Switch Statements
- If-Else Conditions
- Basic Error Handling

## ▶️ How to Run

Compile:

```bash
g++ calculator.cpp -o calculator
```

Run on Windows:

```bash
calculator.exe
```

Run on Linux/macOS:

```bash
./calculator
```

## 📷 Example Output

```text
===== SIMPLE CALCULATOR =====
Enter first number: 20
Enter operator (+, -, *, /): +
Enter second number: 10

Result: 30
```
